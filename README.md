## Установка:
* Клонируйте репозиторий:
  ```
  https://github.com/Alena2312-f/homework3
  ```
* Установите `poetry`
  ```
  pip install poetry
  ```
  Если `poetry` установлен, установите зависимости:
  ```
  # для первичной установки
  poetry install
  # для обновления
  poetry update
  ```
  Для просмотра установленных зависимостей используйте `poetry show --tree`
## Как работать
В данный момент готовы модули:

### category.py 
* создан класс Category со следующими свойствами: название (name), описание (description), список товаров категории (products).
* добавлена инициализация и два дополнительных атрибута (количество категорий: (category_count), количество товаров: (product_count))
* Реализованны геттеры: products: возвращает строку со всеми продуктами в приватном атрибуте products 
и products_in_list: возвращает приватный атрибут products в виде списка.
* Реализованы методы:__str__: возвращает строку в следующем виде:Название категории, количество продуктов: 200 шт.
add_product: метод для добавления продукта в атрибут products;
middle_price: подсчитывает средний ценник всех товаров в данной категории.
* Создан вспомогательный класс - ZeroQuantityProduct: Класс ошибки при нулевом количестве товара.

### product.py
* создан класс Category со следующими свойствами: название (name), описание (description), цена (price), количество в наличии (quantity)
* добавлена инициализация.
* Реализованн геттер и сеттер price для приватного атрибута price
* Реализованы методы:__str__: возвращает строку в следующем виде: Название продукта, 80 руб. Остаток: 15 шт.
__add__: метод для получения полной стоимости всех выбранных товаров на складе;
new_product: класс-метод, который принимает на вход параметры товара в словаре и возвращает созданный объект класса Product
* Созданы вспомогательные классы - ZeroQuantityProduct: Класс ошибки при нулевом количестве товара.
PrintMixin: при создании объекта печатает в консоль информацию о том, от какого класса и с какими параметрами был создан объект

### smartphone.py

### utils.py
* функции `read_json` и `create_objects_from_json`, которые реализуют подгрузку данных по категориями и товарам из файла JSON

### base_product.py
Создан базовый абстрактный класс с именем *BaseProduct*, который является родительским для класса продуктов.
Классы «Смартфон» и «Трава газонная» - наследниками класса *Product* и тем самым наследуют все свойства абстрактного
класса.

### print_mixin.py
Реализован класс-миксин, который при создании объекта печатает в консоль информацию о том, от какого класса и с какими
параметрами был создан объект. Например:
```
Product('Продукт1', 'Описание продукта', 1200, 10)
```
## Тестирование 

### test_category.py
* test_category_init - проверяет инициализацию 
* test_category_products_property - Тестируем геттер, который возвращает строку со всеми продуктами в приватном атрибуте products
* test_category_add_product - Тестируем метод для добавления продукта в атрибут products
* test_category_str - Тестируем строковое отображение товаров в категории
* test_category_add_product_invalid - Тестируем поведение метода добавления продукта в атрибут products при попытке добавить вместо продукта другой объект - вызываем ошибку
* test_category_middle_price - Тестируем метод, который подсчитывает средний ценник всех товаров в данной категории, в том числе и случай, когда в категории нет товаров

### test_product.py
* test_product_init - проверяет инициализацию
* test_product_new_product_identical - Тестируем метод, который принимает на вход параметры схожего по наименованию товара и возвращает измененный объект класса Product
* test_product_new_product_different - Тестируем метод, который принимает на вход параметры отличного от других наименований товара и возвращает созданный объект класса Product
* test_product_price_setter_invalid - Тестируем поведение сеттера для приватного атрибута price в случае если новая цена равна или ниже нуля
* test_product_price_setter_yes - Тестируем поведение сеттера для приватного атрибута price в случае если цена товара понижается при согласии понизить цену
* test_product_price_setter_no - Тестируем поведение сеттера для приватного атрибута price в случае если цена товара понижается при несогласии понизить цену
* test_product_str - Тестируем строковое отображение продукта
* test_product_add - Тестируем метод получения полной стоимости всех выбранных товаров на складе
* test_product_add_invalid - Тестируем поведение метода получения полной стоимости всех выбранных товаров при попытке сложить товары из разной категории - вызываем ошибку
* test_product_init_invalid - Тестируем поведение конструктора при попытке добавить товар разного класса с нулевым количеством, то есть вызываем исключение ValueError
* test_product_new_product_invalid - Тестируем метод new_product, когда он принимает на вход товар с нулевым количеством - вызываем исключение
